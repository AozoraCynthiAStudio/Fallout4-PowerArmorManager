# Fallout 4 动力甲仓库终端设计方案

## 1. 核心定位

这是一个"小型动力甲管理终端"，不是复杂仓库管理软件。

目标：

-   小巧
-   精致
-   设备感
-   适合键盘/手柄操作
-   基于 PrismaUI 2.0
-   不追求鼠标支持

设计重点：

-   简单功能
-   高完成度视觉
-   快速存取动力甲

------------------------------------------------------------------------

# 2. 技术方向

使用 PrismaUI 2.0：

-   CEF + GPU 合成
-   利用 HTML/CSS/JS 制作 UI
-   支持半透明、动画、光幕效果

放弃 PrismaUI 1.0 的原因：

-   纯 CPU 渲染
-   掌机性能压力大
-   容易掉帧

PrismaUI 2.0 优先保证：

-   流畅
-   稳定
-   手柄/键盘体验

------------------------------------------------------------------------

# 3. 整体交互理念

不要做"大型菜单"。

应该像：

-   便携式终端
-   动力甲控制设备
-   小型未来科技设备

而不是：

-   Pip-Boy
-   传统列表菜单
-   电脑终端

------------------------------------------------------------------------

# 4. 主界面设计

## 位置

建议：

-   右侧出现设备
-   小尺寸
-   竖向比例
-   类似未来 PDA / 控制终端

不要：

-   宽屏
-   大窗口
-   复杂实体按键

------------------------------------------------------------------------

# 5. 仓位设计

共 50 个仓位。

第一页展示 10 个。

前 5 个使用默认用途名称，引导玩家理解：

    01 主动力甲
    02 战斗备用
    03 收藏展示
    04 任务备用
    05 空置机位

    06 空置机位
    07 空置机位
    08 空置机位
    09 空置机位
    10 空置机位

设计目的：

让玩家理解：

这是"动力甲停放位置"，不是给动力甲套装命名。

------------------------------------------------------------------------

# 6. 名称逻辑

## 空仓位

显示：

    01 空置机位

状态：

-   灰色
-   未激活

------------------------------------------------------------------------

## 已存储

不显示动力甲自动名称。

显示：

    01 主动力甲
    02 战斗备用

通过颜色/状态标记表示已存。

不要显示：

-   X-01
-   T-60
-   自动型号

原因：

动力甲可能被改装，名称会失效。

------------------------------------------------------------------------

## 自定义名称

允许部分仓位修改名称。

例如：

    02 兄弟会动力甲
    03 核子世界收藏

名称代表：

"这个仓位的用途"

而不是：

"固定动力甲型号"。

------------------------------------------------------------------------

# 7. 主动力甲

01 号仓位固定：

    主动力甲

特点：

-   不允许改名
-   绑定快捷键

快捷键逻辑：

如果主动力甲已存储：

→ 召唤到玩家附近

如果主动力甲已部署：

→ 收回原仓位

------------------------------------------------------------------------

# 8. 状态显示

不要大量文字。

推荐：

使用颜色或简单符号。

例如：

空：

    ○

已存：

    ●

主动力甲：

    ◆

保持界面简洁。

------------------------------------------------------------------------

# 9. 操作按钮

只保留三个功能：

## 1. 召唤 / 存储

根据状态变化：

空仓位：

-   保存当前动力甲

已存：

-   召唤动力甲

------------------------------------------------------------------------

## 2. 改名

用于修改仓位名称。

------------------------------------------------------------------------

## 3. 详情

查看当前动力甲部件。

------------------------------------------------------------------------

# 10. 详情展示

不进入二级页面。

点击详情：

从设备侧边投射信息光幕。

展示：

    头盔
    胸甲
    左臂
    右臂
    左腿
    右腿

只需要六行。

不要：

-   复杂属性
-   装备比较
-   自动分析
-   多余信息

------------------------------------------------------------------------

# 11. UI视觉方向

关键词：

-   Compact
-   Clean
-   Sci-Fi Utility
-   Fallout Future Technology

避免：

-   老旧 CRT 风
-   大量锈迹
-   Pip-Boy 风格
-   复杂机械装饰

推荐：

-   深色外壳
-   半透明屏幕
-   冷色高亮
-   少量发光
-   简洁线条

------------------------------------------------------------------------

# 12. 开发原则

不要增加：

-   自动命名系统
-   动力甲分类
-   多收藏
-   搜索
-   排序
-   部件交换
-   维修系统

保持：

简单功能 + 高质感 UI。

最终目标：

一个玩家愿意经常打开的小型动力甲控制终端。
