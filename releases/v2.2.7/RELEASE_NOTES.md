# Release 2.2.7

## Scope

`2.2.7` is the current GOE release line for the Power Armor Manager. The Chinese and English packages use the same feature baseline while retaining their intentionally independent UI layout tuning.

The feature scope has been verified in-game by the author, including the terminal interface, slot browsing, storage/deployment/recall, renaming, details, and the 50-slot paging flow.

## Assets

- `PowerArmorManager_2.2.7_CHS.zip`
- `PowerArmorManager_2.2.7_EN.zip`

Install only one language package. The ZIP files include the runtime DLL, ESP, compiled Papyrus scripts, PrismaUI resources, MCM configuration, sound assets, and installation notes.

## Dependencies

F4SE, Address Library, MCM, PrismaUI Framework 2.0.2 or later compatible 2.x, and Garden of Eden Papyrus Script Extender (GOE) are required.

## Input contract

The supported interaction model is keyboard/gamepad focus plus wheel scrolling. Mouse focus/click interaction is not part of the supported release contract.
